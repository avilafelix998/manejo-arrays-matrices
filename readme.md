# GUÍA DEL TRABAJO

Este proyecto en **Flask** permite a los usuarios registrar datos de varias personas, tales como nombre, edad y nota, y luego muestra estos datos ordenados por la nota, de mayor a menor.

## Requisitos

Antes de correr el proyecto, asegúrate de tener instalados los siguientes requisitos:

- **Python** (recomendado 3.x)
- **Flask** (puedes instalarlo fácilmente con pip)
