# GUÍA DEL TRABAJO

Este proyecto  permite a los usuarios registrar datos de varias personas, tales como nombre, edad y nota, y luego muestra estos datos ordenados por la nota, de mayor a menor.

## Requisitos


- **HTML** 
- **JAVAESCRIPT**
- **LIVE SERVER**
## Pasos para ejecutar el proyecto

### 1. Clona el proyecto
### 2. Insta la extensión live server
### 3. correr el programa
